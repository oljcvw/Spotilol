# Archive

Files kept for reference only. Nothing in this folder is used by the build or by the in-app updater.

- `art/` – screenshots and icon inherited from Spotilol.
- `release-assets/` – signing notes and checksums of superseded Spotif*ck releases (1.0.6 and 1.0.7). The old APK files themselves were removed; the newest builds are in `/release-assets`.
- `app-unused-res/` – resources the app no longer references: legacy pre-API-26 launcher bitmaps (minSdk is 28, so the adaptive icon is always used), the default Android Studio launcher foreground, and the Play Store icon export.
